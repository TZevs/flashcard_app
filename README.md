## 🎓 About This Project
> This is my mobile development module **assignment** project for Software Engineering at Sheffield Hallam University (2025). It was developed to meet a marking criteria, so it is **not at a production-level standard**.

🫟 **Problem:** Watching my sister revise for her Alevels using paper flashcards and seeing how inconvenient the cards were to create, organise and handle inspired the idea for developing a flashcard app. This app would provide an easy to access organised collection of flashcards that can be accessed anytime without worry of losing any.  

🚪 **Approach:** 

🚦 **Status:** Not Working. During attempts to allow development on MacOS and the the app to run on iPhone, several bugs appeared, still need to be resolved.

### ✨ Features
- Create, edit, and delete decks of flashcards.
- Upload images from gallery or camera onto cards.
- View flashcards with gesture-based navigation and a tap-to-flip interface
- Sign in using email/password or Google account using Firebase Authentication feature.
- Browse and search public decks created by other users
- Store public decks in Firebase database and private decks in an SQLite database.
